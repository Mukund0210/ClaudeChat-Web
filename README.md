# ClaudeChat-Web

A lightweight web-based conversational AI chatbot built with Flask and Anthropic's Claude-3 (Haiku) via LangChain.

## 🔍 Features
- Claude 3 Haiku integration using `langchain-anthropic`
- Flask-powered web interface
- Memory-enabled conversations (via ConversationBufferMemory)
- Clean and minimal design for easy extensibility
